# VEJOTEK – Sistema de Entradas

Sistema web para gestionar 100 entradas digitales de VEJOTEK – Edición Máscaras: socios, ventas, pagos, QR, ingreso y rifas.

## Estructura

- `index.html` — acceso público
- `admin.html` — panel administrativo
- `socio.html` — panel de cada socio
- `ingreso.html` — validación de QR en puerta
- `rifa.html` — control de participantes y rifas
- `supabase/migrations/001_initial.sql` — estructura inicial de base de datos
- `css/styles.css` — estilos
- `js/` — lógica del sistema
